# 炁（Qi）— 修仙挂机小游戏

> 一款以修仙为题材的挂机游戏 | Cocos Creator 3.8 + AI 辅助开发

**核心循环：** 挂机修炼 → 累积修为 → 突破境界 → 解锁功能 → 变强 → 更快修炼

---

## 项目结构

```
Qi/
├── assets/
│   └── scripts/
│       ├── config/          # 配置表（境界/功法/秘境/常量）
│       ├── core/            # 核心框架（事件/数据/存档）
│       ├── systems/         # 游戏系统（修炼/功法/秘境/战力）
│       ├── utils/           # 工具函数（数值/时间）
│       ├── GameManager.ts   # 游戏主控制器
│       ├── UIManager.ts     # UI管理器
│       └── DouyinAdapter.ts # 抖音平台适配
├── settings/                # 项目设置
├── package.json
└── tsconfig.json
```

## 已实现模块

| 模块 | 文件 | 说明 |
|------|------|------|
| 事件总线 | `core/EventBus.ts` | 全局事件中心，18个游戏事件枚举 |
| 玩家数据 | `core/PlayerData.ts` | 运行时数据模型 + 工厂方法 |
| 存档系统 | `core/SaveManager.ts` | 本地存储，30秒自动保存 |
| 境界配置 | `config/RealmConfig.ts` | 5大境界×4阶段=20节点 |
| 功法配置 | `config/TechniqueConfig.ts` | 3本功法：踏雪无痕/太乙真经/混元功 |
| 秘境配置 | `config/DungeonConfig.ts` | 22关秘境 + 2 Boss关 |
| 数值常量 | `config/GameConstants.ts` | 全局数值常量 |
| 修炼系统 | `systems/CultivationSystem.ts` | 修炼增长 + 暴击机制 + 突破判定 |
| 功法系统 | `systems/TechniqueSystem.ts` | 功法选择 + 升级 + 加成 |
| 秘境系统 | `systems/DungeonSystem.ts` | 秘境挑战 + 战力碾压 |
| 战力/离线 | `systems/CombatCalculator.ts` | 战力计算 + 离线收益 |
| 数值工具 | `utils/NumberUtils.ts` | 大数字格式化（万/亿/兆） |
| 时间工具 | `utils/TimeUtils.ts` | 离线时长计算 |

## 本地开发

1. `git clone https://github.com/Thor-Zhuang/Qi.git`
2. 用 Cocos Creator 3.8.6+ 打开项目
3. 在编辑器中创建场景节点并绑定 UI 组件
4. 构建发布为抖音小游戏

## 环境要求

- Cocos Creator 3.8.6+
- 抖音开发者工具 >= 2.0.6
- 调试基础库 >= 1.88.0
