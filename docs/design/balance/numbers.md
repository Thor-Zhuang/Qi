# 数值设计文档

## 核心公式

### 修炼速度
```
每秒修为 = 基础速度 × (1 + 功法加成%) × (1 + 境界加成%)
```

### 战力计算
```
战力 = 境界基础战力 × (1 + 功法加成%)
```

### 离线收益
```
离线修为 = 在线每秒修为 × 0.6 × 离线秒数（上限8小时）
```

## 数值目标

| 指标 | 目标值 |
|------|--------|
| 前三天每天至少突破 | 1次 |
| 练气期总耗时 | ~30分钟 |
| 筑基期总耗时 | ~2小时 |
| 金丹期总耗时 | ~1天 |
| 元婴期总耗时 | ~3天 |
| 化神期总耗时 | ~7天 |
| 8小时挂机修为占比 | 当前境界需求的30-50% |
