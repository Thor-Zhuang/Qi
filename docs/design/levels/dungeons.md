# 秘境关卡设计

## 关卡列表（22关+2Boss）

> 详细数值见 `config/DungeonConfig.ts`，此处为设计思路

### 设计原则
- 前5关：练气期可通，教学引导
- 6-10关：筑基期战力需求
- 11-15关：金丹期战力需求
- 16-20关：元婴期战力需求
- 21-22关：化神期战力需求
- Boss关：阶段末尾，需要特定策略/更高战力

### 关卡命名规则
- 普通关：灵兽/妖兽/阵法名称
- Boss关：知名Boss名称
- 命名风格：仙侠世界观一致
