# 炁（Qi）— 游戏设计文档（GDD）

## 一、游戏概述

- **名称**：炁（Qi）
- **类型**：修仙挂机小游戏
- **平台**：抖音小游戏
- **分辨率**：720×1280 竖屏
- **核心循环**：挂机修炼 → 累积修为 → 突破境界 → 解锁功能 → 变强 → 更快修炼
- **目标受众**：碎片时间玩家，喜欢数字增长快感

## 二、核心玩法

### 2.1 修炼系统
- 自动修炼，每秒获得修为
- 修炼速度 = 基础速度 × 功法加成 × 境界加成
- 修炼暴击：5%概率获得2倍修为
- 加速修炼：看激励视频获得30分钟双倍

### 2.2 境界系统
5大境界 × 4小阶段 = 20个节点：

| 大境界 | 阶段 | 修为需求量级 |
|--------|------|-------------|
| 练气期 | 初期/中期/后期/圆满 | 百~千 |
| 筑基期 | 初期/中期/后期/圆满 | 千~万 |
| 金丹期 | 初期/中期/后期/圆满 | 万~十万 |
| 元婴期 | 初期/中期/后期/圆满 | 十万~百万 |
| 化神期 | 初期/中期/后期/圆满 | 百万~亿 |

- 前中期突破100%成功率
- 化神期开始需要突破丹

### 2.3 功法系统
- 3本功法可选：踏雪无痕/太乙真经/混元功
- 功法可升级，消耗灵石
- 不同功法提供不同修炼加成

### 2.4 秘境系统
- 22关+2Boss关
- 战力碾压判定：攻击方战力 > 防守方战力即胜利
- 通关奖励：灵石+修为

### 2.5 离线收益
- 离线效率 = 在线效率 × 0.6
- 上限8小时
- 可看广告翻倍

## 三、UI结构

### 3.1 主界面
```
┌─────────────────────┐
│  修为:1.2万  灵石:580│ ← 顶部资源栏
│  境界:筑基中期       │
├─────────────────────┤
│                     │
│   [角色立绘区域]     │ ← 中央显示区
│   修为进度条 ████░░  │
│   [修炼] [突破]      │ ← 操作按钮
│                     │
├─────────────────────┤
│ 修炼│功法│秘境│我的  │ ← 底部Tab
└─────────────────────┘
```

### 3.2 面板说明
- **修炼面板**：修炼速度详情、暴击率、加速按钮
- **功法面板**：3本功法卡片、升级消耗
- **秘境面板**：关卡列表、战力对比、挑战按钮
- **个人面板**：角色信息、战力、设置
